# 📚 Website Bán Sách Trực Tuyến (Bookstore E-commerce)

Dự án Website Thương mại điện tử chuyên cung cấp các đầu sách đa dạng. Hệ thống bao gồm giao diện tương tác cho khách hàng (Frontend) và trang quản trị (Admin Dashboard) để quản lý sản phẩm, đơn hàng và doanh thu. 

Dự án được xây dựng theo mô hình **MVC** nhằm phục vụ cho Thực tập tốt nghiệp.

## 🚀 Chức năng nổi bật

### Dành cho Khách hàng (User)
- Xem danh sách sản phẩm và chi tiết sách.
- Thêm sản phẩm vào giỏ hàng (Cart).
- Đặt hàng và theo dõi trạng thái đơn hàng.
- Xem đánh giá (Reviews) sản phẩm.

### Dành cho Quản trị viên (Admin)
- **Dashboard:** Thống kê tổng quan (Stats) về doanh thu và số lượng đơn hàng.
- **Quản lý Sản phẩm (Books):** Thêm, sửa, xóa, cập nhật thông tin sách.
- **Quản lý Đơn hàng (Orders):** Duyệt đơn, cập nhật trạng thái giao hàng và xem chi tiết đơn hàng.

## 🛠️ Công nghệ sử dụng
- **Frontend:** HTML5, CSS3, JavaScript.
- **Backend:** PHP (Kiến trúc MVC).
- **Cơ sở dữ liệu:** MySQL.
- **Môi trường Web Server:** XAMPP (Apache, MySQL).
